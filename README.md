# Kitchen Craze

A self-contained browser cooking game inspired by playful cooking and food-reaction games. It uses original CSS-drawn character art and synthesized sound effects.

## Run it
1. Extract `Kitchen-Craze-GitHub.zip`.
2. Open `index.html` in a browser to play locally.
3. To publish on GitHub Pages, create a repository and upload `index.html`, `style.css`, and `script.js` (or upload the whole extracted folder's contents). In the repository, open **Settings → Pages**, choose deployment from the `main` branch and `/ (root)`, then save.

## Controls
- Select food in the Fridge panel.
- Use Chop, Cook, Blend, Season, and Feed buttons.
- Click kitchen appliances to use them directly.
- Switch between Milo, Luna, and Bo in Friends.
- Sound effects are synthesized in the browser; click Sound On to toggle them.

## Notes
- The game has no backend, account, or external asset downloads. An optional Google Font may load if online; the game falls back to system fonts.
- This is an original prototype, not an official Toca Boca game and does not include Toca Boca's characters, art, or audio.
